# Pricing Notes

*Note: Do NOT implement billing in code at this stage. Record actual partner responses during discovery.*

## 4 Pricing Hypotheses
1. **Platform Fee:** Fixed rate of $1k - $5k / month.
2. **Usage-Based:** Per verified local serve (charging a fraction of the model cost saved).
3. **Enterprise License:** Annual license with predefined traffic tiers.
4. **Hybrid:** Base platform fee + usage overages.

## Discovery Questions for Partners
- "How do you currently measure ROI on infrastructure tools optimizing LLM spend?"
- "What is your comfort level with a black-box percentage-of-savings model vs. a flat fee?"

## Anchoring Questions
- "What would this need to save for $1,000/month to be a trivial expense?"
- "What about $5,000/month?"
