# Security Policy

## Supported Versions

Currently, only the latest release of Microloop is supported with security updates.

## Reporting a Vulnerability

We take the security of Microloop seriously. If you discover a security vulnerability, please do NOT file a public issue. 

Please report any security vulnerabilities by emailing the maintainers directly or using GitHub's private vulnerability reporting feature if enabled on the repository.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If you're curious about the status of your report, feel free to follow up.
